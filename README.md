# Diary Apps
Shop diary: stock, ledger, invoices/courier-ready, customers, subscription. English / বাংলা.
Native Android shell (WebView) + web UI in `app/src/main/assets/index.html`. Data is stored on-device.

## Build the APK on GitHub
1. Push this folder to a GitHub repo (branch `main`).
2. Actions tab -> "Build Diary Apps APK" (runs on push, or press "Run workflow").
3. Open the finished run -> Artifacts -> `DiaryApps-debug-apk` -> unzip -> install `app-debug.apk`.
